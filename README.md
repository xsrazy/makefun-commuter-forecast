One line of weather forecast for a city that does not exist, entered in make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
